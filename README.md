### Selected work

- **Samaaro Events Platform:** a white-label Flutter platform that runs **7 branded production apps from one codebase**. Launching a new client app now takes **~70% less time**, and bugs get hotfixed over the air with Shorebird. <sub>`Flutter` `Firebase` `Fastlane` `Shorebird`</sub>
- **PepsiCo Store Delivery:** an enterprise delivery-routing app with an **offline-first sync engine**, store verification and native maps, built for dense delivery routes. <sub>`Flutter` `SQLite` `Mapbox` `GitLab CI`</sub>
- **Apex Invest Portal:** a fintech app for investors and fund managers, with biometric auth, live fund-analytics charts and automated code signing. <sub>`Flutter` `BLoC` `REST` `Fastlane`</sub>
- **[Namma Wallet](https://github.com/AkashProfessionalCoder/namma_wallet)** (open source): I added home-screen widgets and contributor modules, and set up the **Fastlane CI/CD and release automation**. <sub>`Flutter` `Hive` `GitHub Actions`</sub>
